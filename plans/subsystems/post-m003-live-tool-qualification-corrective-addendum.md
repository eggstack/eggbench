## 1. Purpose

M003 is closed and hosted-qualified for its Eggbench-owned schema, parser,
lifecycle, process, evidence, comparison, and portability contracts.

Its closure records also explicitly preserve one evidence gap: no real
`eggreplay` or `eggprobe` executable was available on the implementation
host or hosted CI runners. Consequently, the complete external-tool path has
not yet been demonstrated against the sibling binaries.

This corrective is additive qualification. It does not reopen or invalidate
the historical M003 closures.

## 2. Finding

The missing evidence is specifically:

1. a real EggReplay binary accepting the exact `validate` and
   `replay --output json` contract used by M003a;
2. a real Eggprobe `v0.1.1` binary accepting the exact schema-0.3 plan
   generated by M003b through `eggprobe run -`;
3. an end-to-end controlled run proving:
   - Eggprobe pre diagnostics;
   - real EggReplay semantic replay;
   - Eggprobe post diagnostics;
   - Eggbench evidence/gating;
   - teardown;
4. a real semantic mismatch proving nonzero EggReplay findings remain a
   successful workload observation and fail the normal absolute correctness
   gate rather than becoming a process failure.

The existing fixture/parser tests remain valid but are not a substitute for
this evidence.

## 6. Closure conditions

C001 closes only when one evidence set demonstrates all of the following:

1. exact sibling source/tag identities are recorded;
2. real binary SHA-256 values are recorded;
3. EggReplay `--version`, `validate`, and replay JSON contracts pass;
4. Eggprobe `--version` and schema-0.3 stdin-plan handshake pass;
5. a real matching semantic replay produces zero findings;
6. a real changed response produces nonzero findings without
   `WorkloadFailed`;
7. the zero-findings absolute gate fails normally for that mismatch;
8. real pre/post Eggprobe diagnostics execute around the workload;
9. diagnostic timings stay outside TrialMetrics;
10. a combined M003 run finalizes a valid immutable bundle;
11. cleanup/teardown succeeds;
12. existing default/all-feature/MSRV tests remain green;
13. a fresh four-lane hosted run on the corrective HEAD is green;
14. a closure record is committed and planning state is reconciled.

If the external binaries reveal a substantive contract defect, stop and
re-plan rather than marking the historical M003 closure incorrect or silently
changing sibling ownership.

## 7. C001 outcome (2026-09-25): stopped, C002 registered

C001 executed live against the exact pins and stopped per its own sections 18
and 22. The real `eggprobe v0.1.1` rejects the exact Eggbench-generated
schema-0.3 plan (exit 2, invalid plan) because the M003b adapter emits a
dialect the real binary never spoke: plain-string `probes`, `deadline_ms`
execution, and `tls`/`http_url` target fields (real: typed `kind`/`port`/`url`
probes, microsecond `deadline`, host-and-port-only target); the report reader
likewise expects `family`/`pass`/`fail` where the real binary emits
`kind`/`ok`/`failed`. No production file was modified; the EggReplay side
matched exactly. Full evidence:

The narrow production correction plus the deferred live qualification is
handed off as C002 (section: Implementation handoff, above). Until C002
closes, the live external-tool contract remains qualification-outstanding and
