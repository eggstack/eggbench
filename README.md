# Eggbench

Eggbench is a local-first experiment and evidence system for repeatable software performance and qualification work. The foundation now validates typed experiment plans, resolves them against declared driver capabilities, and defines immutable evidence bundles. Process execution and comparison capabilities are planned separately.
